# Quintana Private Pools — 3D Interactive Map (sample)

A beginner-friendly Vite + Three.js prototype. It includes:
- Welcome screen that opens the three-pool resort overview
- Three selectable sample pools
- Day and night lighting modes
- Clickable pool water and nearby sample objects
- Pool information panel with sample dimensions, depth, and features
- Selectable item list with visual highlighting
- Orbit, zoom, and pan controls

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the VS Code terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```
4. Open the localhost URL printed by Vite (usually http://localhost:5173).

## Important prototype note

The three pools' placement, sizes, depths, and facilities are illustrative placeholders. They are not verified measurements or an accurate survey of Quintana Private Pools. Replace these with owner-confirmed measurements, photos, and facility information before presenting the map as an actual resort layout.
